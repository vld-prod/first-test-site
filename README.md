# Toolbox — многофункциональный сайт

Статический сайт для GitHub Pages без сборки: HTML, CSS и JavaScript.

## Разделы

- **Переводчик** — по умолчанию MyMemory, можно подключить DeepL API по ключу (ключ хранится только в браузере).
- **Конвертер валют** — курсы от Frankfurter API.
- **Генератор паролей** — криптографический Random, оценка силы.
- **QR-коды** — генерация и скачивание PNG.
- **JSON-форматер / валидатор** — форматирование, минификация, проверка.

## Запуск локально

Открой `index.html` в браузере или запусти локальный сервер:

```bash
python3 -m http.server 8080
```

## GitHub Pages

В репозитории настрой Pages: Source = Deploy from a branch, Branch = `main`, Folder = `/ (root)`.

## Безопасность

Сайт статический. Не вводи секретные API-ключи на чужих устройствах: ключ DeepL хранится в `localStorage`.
