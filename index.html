Переводчик

По умолчанию использует бесплатный MyMemory. Можно подключить DeepL API по ключу.

Подключение DeepL API

Ключ хранится только в браузере (localStorage). Публичный сайт не место для постоянного секрета — используй только свой браузер.

DeepL не подключён: перевод через MyMemory.
Как получить ключ
  1. Зарегистрируйся на deepl.com/pro и создай API key.
  2. Вставь ключ сюда, выбери Free/Pro.
  3. Перевод будет пытаться идти через DeepL; при ошибке CORS/network автоматически откатится на MyMemory.

Конвертер валют

Курсы от Frankfurter (ECB). API бесплатный и без ключа.

—

Идеи для пользы

  • Сравнивай курс перед покупкой за рубежом.
  • Используй как быстрый калькулятор для путешествий.
  • Добавляй свои часто используемые пары и проверяй кросс-курс.
  • API без регистрации — можно развернуть на GitHub Pages и пользоваться с телефона.
